# BlockStudioDiamond

A simple BlockStudioDiamond Framework for Auto scaling.

With BlockStudioDiamond, you get a lightweight tool that stays out of your way.

**What you get**

- A simple BlockStudioDiamond Framework for Auto scaling

## Key Features

- A simple BlockStudioDiamond Framework for Auto scaling

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockStudioDiamond.git`
2. `cd BlockStudioDiamond`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure BlockStudioDiamond, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
